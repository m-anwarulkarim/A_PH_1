## সমাধান করা সমস্যাগুলো

1. **`filterEvenNumbers`**: শুধু জোড় সংখ্যাগুলো খুঁজে বের করে।
2. **`reverseString`**: লেখাকে উল্টো করে দেয়।
3. **`checkType`**: ইনপুট লেখা (String) নাকি সংখ্যা (Number) তা বলে দেয়।
4. **`getProperty`**: অবজেক্ট থেকে নির্দিষ্ট কোনো মান বের করে আনে।
5. **`toggleReadStatus`**: বই পড়া হয়েছে কি না (`isRead`) তা সেট করে।
6. **`Person` ও `Student`**: শিক্ষার্থীর নাম, বয়স ও ক্লাসের গ্রেড দেখায়।
7. **`getIntersection`**: দুই পাশের কমন সংখ্যাগুলো খুঁজে বের করে।
